1. overview
=================================================================

specs:
  - Lua 5.4 VM with 6M operations per sec
  - 512 KB Memory
  - 16-Bit Display with 128 * 96 resolution
  - 9 buttons per player (which is 2)
  - 4 PCM/BRR Channels
  - 16 MB cassette slot
  - Unlimited Flashrom for saving

memory map:
 0x00000u-0x05FFFu  VRAM Framebuffer (128x96, 24KB)
 0x06000u-0x06400u  Palette RAM (512 slots, 1KB)
 0x06440u-0x0644Fu  Input State Registers
 0x06450u-0x065FFu  SPU Audio Registers
 0x06600u-0x068FFu  BIOS Font (Packed 1-bit, 5x5 Matrix)
 0x06900u-0x0A8FFu  Sprite Bank 0 & 1 (8KB each)
 0x10400u-0x203FFu  SPU Soundbank RAM (Baked BRR Payloads, 64KB)
 0x20400u-0x403FFu  Tilemap Data Block (128KB)
 0x40400u-0x7DFFFu  Cartridge RAM / Sequencer Stream (~256KB)
 0x7E000u-0x7FFFFu  SRAM Flash Save RAM (8KB)
 
i/o map:

 hardware camera / clip + bank switcher:
 0x06400u 		    Camera X position (16-bit)
 0x06402u			Camera Y position (16-bit)
 0x06404u			Clip Enable 
 0x06405u 			Clip X0
 0x06406u 			Clip Y0
 0x06407u 			Clip X1
 0x06408u 			Clip Y1
 0x06409u 			Active Sprite Bank
 
 apu registers:
 0x06450u + (ch*10) 	Channel's Status
 0x06451u + (ch*10)	Channel's Trigger
 0x06452u + (ch*10)	Channel's Loop Boolean
 0x06453u + (ch*10) 	Channel's Address (LO)
 0x06454u + (ch*10) 	Channel's Address (HI)
 0x06455u + (ch*10) 	Channel's Length (LO)
 0x06456u + (ch*10) 	Channel's Length (HI)
 0x06457u + (ch*10) 	Channel's Volume
 0x06458u + (ch*10) 	Channel's Pitch
 0x06459u + (ch*10)	Channel's Buffer (only half is exposed though)
 0x06492u			Hardware Tracker Enable
 0x06493u			Hardware Tracker Volume
 0x06498u			Hardware Tracker Song Order Index
 0x06499u			Hardware Tracker Song Row Index
 0x0649Au			Hardware Tracker Song Pattern Index
 0x06490u-0x0650Fu 	Hardware Oscilloscope Ring Buffer

 input registers:
 0x06440u-0x06443u	Current Input Mask (32 bit)
	 Byte 0 [0x06440u] - Player 1 Low Byte Configuration
		Bit 0   DPAD_LEFT
		Bit 1   DPAD_RIGHT
		Bit 2   DPAD_UP
		Bit 3   DPAD_DOWN
		Bit 4   BUTTON_A
		Bit 5   BUTTON_B
		Bit 6   BUTTON_C
		Bit 7   BUTTON_D

	 Byte 1 [0x06441u] - Player 1 / Player 2 Split Matrix
		Bit 0   BUTTON_START
		Bit 1   P2_DPAD_LEFT
		Bit 2   P2_DPAD_RIGHT
		Bit 3   P2_DPAD_UP
		Bit 4   P2_DPAD_DOWN
		Bit 5   P2_BUTTON_A
		Bit 6   P2_BUTTON_B
		Bit 7   P2_BUTTON_C

	 Byte 2 [0x06442u] - Player 2 High Byte Configuration
		Bit 0   P2_BUTTON_D
		Bit 1   P2_BUTTON_START
		Bit 2-7 Reserved / Always Return 0

	 Byte 3 [0x06443u]
		Bit 0-7 Unused
 0x06444u-0x06447u	Previous Input Mask
  	 Mirrors the Current Input Mask, but is used for delta-state triggers
